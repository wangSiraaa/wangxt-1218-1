## 1. 产品概述

司法电子证据管理系统用于保障电子证据在“公安移交 → 检察院审查 → 法院调阅”全链路的完整性与不可篡改性。系统通过 SHA-256 哈希校验确保证据入库前未被破坏，已采纳证据不可覆盖原文件，所有调阅下载均留存案件、人员和用途审计日志，为司法诉讼提供可信的电子证据链。

- 解决问题：电子证据在跨部门流转中易被篡改、覆盖、无痕调阅，导致证据效力存疑。
- 目标用户：办案人员（公安）、检察官、书记员（法院）。
- 价值：形成“上传即校验、采纳即冻结、调阅即留痕”的闭环证据链路。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 办案人员（公安） | 管理员分配账号 | 上传电子证据包与哈希值、查看本人案卷证据 |
| 检察官 | 管理员分配账号 | 审查证据、标记采纳意见、查看调阅日志 |
| 书记员（法院） | 管理员分配账号 | 调阅证据、下载庭审展示副本、登记调阅用途 |
| 系统管理员 | 预置账号 | 用户与权限管理、节点配置、全局日志审计 |

### 2.2 功能模块

1. **登录页**：账号密码登录，按角色进入对应工作台。
2. **案卷工作台**：案件列表与详情、证据清单、链路状态时间线、角色化操作入口。
3. **证据上传页**：上传证据包、填写哈希值、即时哈希校验、校验失败拒入库。
4. **证据审查页**：检察官查看证据、标记采纳/不采纳意见、已采纳证据锁定不可覆盖。
5. **调阅管理页**：书记员登记调阅用途、生成庭审展示副本、下载即留痕。
6. **调阅日志页**：按案件/人员/用途/时间检索调阅记录，证据链路审计。
7. **系统管理页**：用户、角色、权限维护。

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 登录表单 | 账号密码校验，角色路由分发 |
| 案卷工作台 | 案件列表 | 案件卡片/表格、状态筛选、新建案件 |
| 案卷工作台 | 证据清单 | 证据条目、哈希摘要、链路状态、采纳标记 |
| 案卷工作台 | 链路时间线 | 公安移交→检察院审查→法院调阅的可视化时间线 |
| 证据上传页 | 上传与校验 | 拖拽上传、SHA-256 实时计算、哈希比对、失败拦截 |
| 证据审查页 | 采纳意见 | 查看证据详情、采纳/不采纳、意见备注、冻结原文件 |
| 调阅管理页 | 调阅申请 | 选择证据、填写用途、生成展示副本、下载 |
| 调阅日志页 | 审计查询 | 多条件检索调阅记录、导出、链路完整性展示 |
| 系统管理页 | 用户权限 | 用户增删改、角色分配、权限配置 |

## 3. 核心流程

**证据生命周期主流程**：办案人员上传证据包与哈希值 → 系统计算 SHA-256 并比对，失败则拒入库 → 校验通过后证据入库并冻结哈希 → 检察官审查并标记采纳意见，已采纳证据原文件不可覆盖 → 书记员登记调阅用途并下载庭审副本 → 系统记录案件、人员、用途形成调阅日志 → 链路全程可审计回溯。

## 4. 用户界面设计

### 4.1 设计风格

- 主色：司法深靛蓝（#1B2A4A）作为权威主色，辅以证据金（#C8A24B）作为强调色；中性基底采用深石板灰（#0F172A）与羊皮纸白（#F5F1E8）形成“卷宗”质感。
- 次色：链路状态采用语义色（青绿=已采纳、琥珀=待审查、朱红=校验失败/已退回）。
- 按钮：直角微圆角（4px）、实心主按钮 + 描边次按钮，强调克制与权威感。
- 字体：标题使用思源宋体（Noto Serif SC）传递司法卷宗感，正文使用 HarmonyOS Sans / 思源黑体保证可读性。
- 布局：顶部窄导航 + 左侧案件树/筛选 + 右侧主工作区，卡片化分块。
- 图标：线性图标，与 Ant Design Vue 风格统一。

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 登录页 | 登录表单 | 深色卷宗背景、居中卡片、主色实心按钮 |
| 案卷工作台 | 案件列表 | 顶部统计卡、筛选栏、案件表格、状态标签 |
| 案卷工作台 | 链路时间线 | 垂直时间线、部门节点、状态徽章 |
| 证据上传页 | 上传与校验 | 拖拽区、哈希进度、校验结果提示 |
| 证据审查页 | 采纳意见 | 证据预览、意见表单、冻结锁标识 |
| 调阅管理页 | 调阅申请 | 证据选择、用途表单、副本生成按钮 |
| 调阅日志页 | 审计查询 | 高级筛选、日志表格、链路完整性指示 |

### 4.3 响应式

桌面优先（1280px+ 为主），中屏自适应栅格，触控优化按钮命中区域；关键审计页面保持桌面布局以确保信息密度。

### 4.4 3D 场景指引

不适用（本系统为业务工作台，无 3D 需求）。
